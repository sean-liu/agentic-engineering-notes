# Agentic Engineering Notes

Public field notes from hands-on experiments with coding agents, reusable agent capabilities, durable state, evaluation, and developer workflows.

This repository is an outward-facing technical publication surface. It is intentionally narrower than my private working systems and research notes: the goal is to publish engineering lessons that are useful and falsifiable without exposing private implementation details or overstating maturity.

## What I write about

- coding-agent and AI-assisted software-development workflows;
- context, durable state, provenance, and long-running agent behavior;
- evaluation, failure analysis, and historical replay;
- developer tooling and reusable agent capabilities;
- governance and authority boundaries when agents modify durable artifacts;
- lessons from dogfooding these ideas in real engineering work.

## Publication stance

These are field notes, not framework announcements.

I distinguish observed behavior, working hypotheses, implemented mechanisms, validated results, and planned work. When the evidence is still local or incomplete, I keep the claim narrow rather than presenting an internal experiment as a general result.

The public repository contains curated derivatives only. Private project details, confidential material, internal operating instructions, and reproducible private-system mechanics stay out of this repository.
